GitHub 因 AI 流量暴增撐不住，微軟救援竟找上對手 AWS - 深度摘要：由微軟（Microsoft）全資擁有的全球最大程式碼代管與協作平台 GitHub，近期因全球開發者瘋狂且密集地使用其 AI 輔助開發工具（如 GitHub Copilot），導致其後端雲端運算需求與 API 流量出現了始料未及的爆炸性成長，頻繁發生伺服器服務不穩與算力容量吃緊的極度窘境。令人跌破眼鏡的是，為了解決影響全球開發者的燃眉之急，微軟並未選擇完全依賴自家的 Azure 雲端基礎設施，而是破天荒地選擇尋求其在雲端市場的最大頭號競爭對手——亞馬遜（AWS）的雲端運算資源來緊急支撐 GitHub 的龐大底層需求。這戲劇性的一幕凸顯了當前 AI 運算所帶來的基礎設施極端壓力，甚至已超越了單一科技巨頭的算力承載極限。 - 事件背景與產業衝擊：這起極具話題性的事件無意間打破了雲端巨頭間為了維持面子而絕對封閉競爭的市場迷思，展現了在極端且難以預測的 AI 算力渴求下，企業採用「多雲架構（Multi-Cloud）」分散風險的現實絕對必要性。同時這也向業界證明了，AI 輔助軟體開發工具的爆發採用速度，已遠遠超過了傳統雲端資料中心的按部就班擴容規劃，底層算力基礎設施的跨平台彈性調度能力將成為未來雲端服務商的勝負關鍵。 - 未來觀察重點：身為雲端二哥的微軟在經歷此次事件後，後續將如何大幅調整資本支出以擴建 Azure 專屬的 AI 算力農場，從而降低對最大對手的尷尬依賴；以及這種罕見的「競合（Coopetition）」跨雲端合作模式，是否會因為 AI 算力短缺的常態化，而成為未來科技巨頭應對突發流量的行業新常態。 - 原文連結
